AINCRAD CONTROL PANEL — INSTALLATION RAPIDE

1. Déposez ce dossier chez votre hébergeur PHP (version 8.0 ou plus récente).
2. Ouvrez l'adresse de votre site dans le navigateur.
   (Pour essayer sur votre PC : ouvrez un terminal dans ce dossier,
    lancez « php -S localhost:8000 » puis allez sur http://localhost:8000)

DOSSIERS À RENDRE MODIFIABLES PAR PHP (chmod 775) :
- data/                  (données du site + connexion à votre agent)
- uploads/proofs/
- uploads/backgrounds/   (images de fond téléversées depuis le Site builder)

RELIER VOS BOTS — TOUT SE FAIT DANS LE SITE, AUCUN FICHIER À MODIFIER :
  Créateur (⚙️) > Mes bots (🤖) > encadré « 🔗 Connexion à votre agent »
    • Adresse de l'agent : http://IP-de-votre-serveur:PORT
      (la même valeur que AGENT_URL dans votre dashboard ;
       ce n'est NI le Client ID du bot, NI l'adresse de votre site)
    • Clé de l'agent : la valeur AGENT_KEY du config.env de votre agent
    • Cliquez sur « 🔌 Tester et enregistrer »

  Le site appelle vraiment votre agent :
    ✅ il répond        -> c'est enregistré, et vos bots apparaissent
                           aussitôt dans la liste « Nom chez l'agent »
    ❌ il ne répond pas -> RIEN n'est enregistré, et le site vous dit
                           précisément pourquoi (clé refusée, port fermé,
                           adresse d'un autre service…)

  Ensuite : choisissez le bot dans « Nom chez l'agent »,
  cliquez sur « 💾 Enregistrer les bots » puis « 🔄 Synchroniser ».

  À noter : si votre dashboard est installé dans un sous-dossier
  « dashboard », le site reprend automatiquement ses réglages —
  vous n'avez alors rien à saisir.

  Sans agent joignable, le site tourne avec des données de démonstration.

METTRE UN MOT DE PASSE (fortement conseillé en ligne) :
Ouvrez config.php et renseignez SITE_ADMIN_PASSWORD. La lecture du site
reste publique, mais toute modification demandera ce mot de passe
(cadenas 🔒 en haut à droite). Sans mot de passe, n'importe qui trouvant
l'adresse de votre site peut tout modifier.

PERSONNALISER LE SITE :
Ouvrez l'onglet « Site builder » dans le menu : couleur, police, style des
boutons, arrondi, fond (votre image/GIF ou un fond animé), navigation,
effets et CSS libre. Tout se prévisualise en direct, puis « Enregistrer ».

EN CAS DE PROBLÈME :
Ouvrez votre-site/api.php?action=selftest — cette page liste en clair ce
qui va et ce qui bloque (droits d'écriture, version de PHP, agent joignable
ou non, mot de passe configuré ou non).
